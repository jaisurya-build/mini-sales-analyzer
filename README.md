# Mini Sales Analyzer

A beginner-friendly Python project that analyzes sales data using CSV files.

## Features
- Reads sales data from CSV files.
- Calculates total revenue.
- Calculates average transaction value.
- Groups revenue by product.
- Identifies the top-performing product.
- Displays a formatted sales report.

## Technologies Used
- Python 3
- CSV Module

## Project Structure

```text
mini-sales-analyzer/

```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python analyzer.py
```
